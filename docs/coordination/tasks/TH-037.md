`tig help`, `tig --help`, `tig -h`: 한국어 시작 순서·요청/수행 흐름·게시 답변 의미·전체 명령을 용도별 안내. `tig help work`, `tig help request publish`와 기존 명령별 `--help`는 상세 옵션·사용 예시를 표시한다. 명령 등록 목록을 사용하므로 새 명령도 전체 도움말에서 누락되지 않는다. README/USER_GUIDE의 진입 안내와 issue --yes 예시를 정리한다.
