## 승인·범위

P-068 사용자 지시. tig 단독 실행에서 폴더·작업을 묻고 최초 연결·공식 로컬 AI 명세 작성·최종 공유 확인·게시·실패 복구를 안내한다. 기존 advanced 명령과 서버 계약을 유지한다. 터미널 UI는 CLI 담당 범위이며 륜호 웹 TH-030과 분리된다.

## 검증·인계

실제 AI 사용과 공개 저장소 업로드 없이 provider process 경계 및 wizard 통합/취소/재시도 검증을 먼저 수행한다. 로컬 AI의 기존 대화 자동 상속이나 모델 지원을 추정하지 않는다. 유찬은 구현·검증, 륜호는 기존 웹 온보딩을 진행하며 새 CLI 안내를 참고한다.

## 구현 결과

CLI 0.4.0에 기본 대화형 진입점, 최초 기기/GitHub/프로젝트/Codex 연결 안내, 자연어 명세 자동 생성, 누락 조건 질문, 공유 파일 선택, 미리보기·게시·저장 후 재시도 구현. prepare에서 AI가 읽은 파일과 현재 파일 차이를 검증한다. 실제 구독 추론 및 외부 공개 GitHub 쓰기는 실행하지 않았다. [검증 보고](../../verification/TH-034-interactive-requester.md)와 [사용법](../../REQUESTER_QUICKSTART.md)을 따른다.

유찬: PR8→PR9 순서로 리뷰/병합 결정 후 사용자 지정 작은 프로젝트로 실제 Codex 명세·공개 게시 확인. 륜호: TH030 웹 온보딩에서 새 단일 명령 안내와 연결/오류복구 화면을 반영한다. 실제 수행자 runner/Claude 자동 작성/외부 출시/OS별 실증은 후속이다.

## 0.4.2 Codex 설치 탐지 수정

TIG_test에서 VS Code 확장에 포함된 Codex가 일반 터미널 PATH에 없어 미설치로 안내되었다. PATH/사용자 local bin을 우선하고 기본 VS Code/Remote/Insiders 확장에서 현재 OS·CPU용 실행 파일을 탐색한다. 실행 권한·확장 metadata·obsolete 목록을 확인하고 최신 숫자 버전을 우선한다. 기존 readiness 및 ChatGPT 인증 검사 유지. 륜호는 웹 설치/복구 안내에서 확장 설치 사용도 참고하고, 유찬은 저장된 요청을 다시 실행해 실제 명세 작성·게시를 확인한다.

## 0.4.1 사용자 실사용 피드백

TIG_test의 solve this 상태는 요청만 저장되고 candidate/pending이 없었다. 기존 보상 질문이 AI 작성 이후였으며 실제 게시/예치 증거는 없었다. 보상은 AI 전에 사용자 텍스트에서만 수집하도록 변경하고 AI 제시 금액을 무시한다. 한글 메뉴/자연어 안내, 내장 서버 주소·명시 override 재연결, 같은 폴더 재실행 질문 생략, 새 파일 포함 단일 질문과 --select-files를 적용했다. 사용자 테스트 폴더/기존 세션을 삭제하거나 대신 공개 게시하지 않았다.
