## 목표와 완료 조건

1. **폴더 확인**: `tig`는 항상 후보 폴더(지금 폴더가 Git 프로젝트면 그것, 아니면 최근 로컬 AI 세션 폴더, 아니면 마지막 tig 프로젝트)를 보여 주고 `Is this the folder to hand off?`를 묻는다. Enter=yes. no면 `Which folder?`에 경로 또는 프로젝트 이름(알려진 폴더에서 이름 매칭)을 자연어로 받는다.
2. **자연어 조건, AI 초안 제거**: 작업 내용·수행자 도구(codex/claude)·모델·추론 수준·TIG를 한 문장에서 읽고, 빠진 항목만 하나씩 묻는다. tig가 도구·모델·수준·보상을 추천/산정하지 않는다(`recommend.ts`, `reward.ts` 삭제, 로컬 AI 초안 호출 제거). request.md는 요청자의 답(작업, 완료 기준)과 프로젝트 사실(브랜치·최근 커밋·설치/테스트 명령 감지)로만 작성한다. 완료 기준(acceptanceChecks)은 정산 검증의 근거라서 요청자가 직접 쓴다(Enter=요청 문장).
3. **전체 파일 + 요청별 새 저장소**: 작업 트리 전체(gitignore 제외분 제외, protected path와 secret gate는 유지)를 매 요청마다 새로 만드는 public 저장소에 올린다. 서버 project 행은 요청마다 생성한다.
