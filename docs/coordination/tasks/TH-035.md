## 승인·범위

사용자의 실제 게시 결과 확인, 질문/절차 최소화 UX 개선 검토와 수행자 구현 지시. 공개 Git과 웹의 고정 스냅샷 및 400 TIG 예치를 읽기 전용 확인한다. 마지막 게시 메뉴를 간단한 질문으로 바꾸고, 결정 위임 후 반복 질문을 줄인다.

수행자 `tig work`는 본인 요청을 선택해 실제 공식 Codex 코드 작성·수행내역서·로컬 Git 결과를 만드는 개인 체험부터 연결한다. 모델/추론은 공식 목록과 대조하며 미지원 조건을 임의 대체하지 않는다. 프로젝트 명령 실행 격리가 현재 호스트에서 실패하므로 테스트 미실행/미제출을 명시한다. 일반 타인 작업 claim/검사/제출/정산 guard를 풀거나 자기 거래로 TIG를 지급하지 않는다. provider 자격/허용 검증 완료를 주장하지 않는다.

## 검증·인계

고정 snapshot hash/경로 검증, 원본 보존, 실제 AI adapter 경계, 취소·재실행·중복 실행 방지, 모델 오류 및 결과 Git 기록을 검증한다. 실제 사용자 요청에 대한 AI 호출은 사용자 자신의 `tig work` 동의로 시작한다. 공개 Git 쓰기나 지급을 대신 실행하지 않는다. 륜호 TH-030 웹 범위는 유지하고 새 CLI/결과 확인 안내를 참고한다.

## 구현·검증 결과

CLI 0.5.0 설치, 마지막 게시 질문과 단일 맥락 확인, 본인 요청 Codex 생성·보고서·로컬 Git·재열기 구현. 설치본 집중 검사 33개 통과. 실제 게시 Git/API 내용 및 모델 목록 읽기 검증 성공. [검증 보고](../../verification/TH-035-worker-trial.md), [UX 검토](../../ux/requester-posting-review.md), [수행자 사용법](../../WORKER_QUICKSTART.md). 일반 거래의 실행/제출 guard 유지.

유찬: PR8→PR9→PR10 CI·리뷰/병합 결정, 본인 요청으로 tig work 동의 후 실제 생성 확인. 이후 격리 허용 환경과 필수 검사 runner를 확보해 일반 거래 연결. 륜호: 새 요청자/개인 수행자 CLI의 설치·결과 확인·실패 복구 안내를 웹에 반영하며 개인 체험을 지급 완료로 표시하지 않는다.
