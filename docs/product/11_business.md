## 현재 기준

기존 기준: TIG와 현금 분리. 광고/스폰서는 초기 수익 후보.
근거와 확정 결정은 [확정사항](00_confirmed.md)을 따른다. 아래 질문은 별도 결정 전까지 모두 미결정이다.

## 주간 혜택과 보류된 미사용 여유 마케팅 — P-029~031

P-031 최신 결정: 당장은 플랜·가격별 주간 기본 TIG 지급만 제공한다. 아래 P-030 캠페인·개인화 공유 제안은 후속 아이디어로 보관하고 베타 구현 범위에서 보류한다.

P-029: 초기 사용자 확보를 위해 매주 TIG를 지급한다. 지급량·자격 등은 [TIG 경제](05_credits.md)에서 정한다.
P-030: 계산 가능한 미사용 이용 여유를 보여주고 TIG 혜택으로 연결하는 바이럴·마케팅 방향이다. 과거 구독 전체 기간의 정확한 손실량을 조회할 수 있다는 약속은 하지 않는다. [관측 근거와 한계](14_usage_and_drafts.md)를 따른다.
UX 제안: “매주 TIG로 필요한 작업을 맡기고, AI 사용량에 여유가 있을 땐 작업을 도와 TIG를 더 모으세요.”
개인화/공유 카드 제안: 관측 기간·출처가 있는 사용 여유와 실제 TIG 지급/획득 결과를 표시한다. 공유는 사용자가 선택한다. 캠페인의 추가 보너스·추천인 보상·베타 포함 범위는 미정이다.
Tokenisgold 자체 지원이라는 지급 주체를 명확히 하고, OpenAI/Anthropic의 환불·공식 제휴·미사용 token 교환으로 오해시키지 않는다.
마케팅 효과는 가설이며 가입 수뿐 아니라 첫 작업 게시·수행 완료·다음 주 재방문을 함께 검토한다.

## 데이터 기반 경쟁력 — P-040

작업 요구·실행 조건·검사 근거·정산 결과가 연결된 데이터를 축적하는 [전략 초안](17_data_strategy.md)을 검토한다. 집계 지표는 투자 설명, 비교 리포트/평가 데이터는 후속 상품 후보이며 매출이나 투자 가치를 보장하지 않는다.

## 핵심 가치 문구 제안

“AI 사용량이 남을 땐 TIG를 벌고, 부족할 땐 작업을 맡기세요.”
P-009에 따라 기존 구독과 익숙한 공식 도구를 활용하는 편의성을 설명한다. 추가 설정을 줄인다는 목표이며, 모든 구독의 지원·무제한 사용·추가 비용 없음·provider 승인을 약속하지 않는다.

## 공개 설명 원칙

현재 지원하는 도구·검증 수준·작업 범위를 정확히 설명한다.
남은 quota를 저장하거나 양도하는 기능이라고 오해시키지 않도록 작업 결과와 TIG 교환 구조를 설명한다.
약관·특허·상표 판단은 검증된 사실 없이 확정하지 않는다. 필요 시 별도 조사와 전문 검토를 거쳐 결정한다.

## 결정 후 반영

관련 질문 ID에 확정 P-xxx를 연결하고, 동작·예외·완료 조건 및 영향받는 작업/계약을 갱신한다.

## 데이터 정책 확정 — P-057~066

수집/프로젝트 식별/분류·자료 보존/분석 보존·30일 오류 로그/백업·선택 분석 기본 꺼짐·내보내기/삭제·인사이트 권한/공개 집계 기준·일일 집계를 확정했다. [확정 데이터 정책](22_data_decisions.md)을 최신 기준으로 적용한다. 이전의 보존/동의 전면 미정 표현은 이 결정으로 대체하며 정책 문구·필드·권한/삭제의 실제 구현 검증은 남아 있다.
