# GitHub·권한·데이터 보호

## 현재 기준

기존 기준: Git 작업 자동화, consumer AI 계정 credential 수집 금지. P-044 GitHub 공개 가입, P-045 첫 베타 공개 GitHub 저장소만 지원.
근거와 확정 결정은 [확정사항](00_confirmed.md)을 따른다. 아래 질문은 별도 결정 전까지 모두 미결정이다.

## 맥락 인계와 분석 데이터

P-014·016에서 기존 작업 맥락과 수행 기록 전달을 목표로 한다. 전체 대화/비밀정보를 자동 공개하는 것으로 해석하지 않는다.
Git에 남길 인계서·수행내역서와 DB의 운영 지표를 구분하고 수집/보존 범위는 FLOW-03·07에서 결정한다.
UX 예시: “작업에 필요한 요약과 선택한 코드만 인계합니다.” 실제 선별 기능과 일치할 때만 안내한다.

## 데이터 축적 전략 — P-040

[데이터 전략 초안](17_data_strategy.md)에 거래 지표·품질 근거·권리/동의 이력을 함께 설계한다. 이번 방향은 P-021의 로컬 초안 저장·게시 시 필요한 내용 전송 원칙을 대체하지 않는다.
운영에 필요한 정보, 선택적 분석 원문, 외부 제공 후보를 구분한다. 공개 저장소도 수집·재배포·학습에 필요한 조건을 확인한 것으로 간주하지 않는다. 보존기간·삭제·가명처리·재식별 위험과 판매 허용 범위는 미정이다.

## 권한 확정 산출물

Requester/Worker/Tokenisgold App/관리자 각각이 읽고 쓰고 실행할 수 있는 자원을 표로 작성한다.
Public repo only로 정하더라도 외부 코드를 실행할 때의 로컬/서버 격리 문제는 별도로 설계한다.
보호 수준과 수집 정책을 선택하는 문서이며 현재 보안 구현 완료를 선언하지 않는다.

## 결정 후 반영

관련 질문 ID에 확정 P-xxx를 연결하고, 동작·예외·완료 조건 및 영향받는 작업/계약을 갱신한다.

P-021: 선택한 프로젝트의 인계 초안은 로컬에 자동 저장하고 게시 요청 시 필요한 내용만 서버로 보낸다. [DRAFT-01](14_usage_and_drafts.md)의 상세 저장 필드·보존/삭제는 미정이다. 전체 대화 업로드나 자동 공개 Git 커밋에 대한 승인은 아니다.

## 공유와 결과 반영 확정 — P-050·052

선택 프로젝트의 필요한 추적/미커밋 코드와 요약만 공유하며 미추적 파일은 포함 목록을 확인받는다. 결과는 PR·별도 Apply changes로 반영하고 충돌은 덮어쓰지 않는다. 계정 인증/공식 AI 네트워크와 외부 프로젝트 실행 권한을 분리 설계한다.
승인 원문과 범위는 [결정 묶음 2](20_decision_batch_two.md) 및 [확정 기록](00_confirmed.md)을 따른다. 이전 질문 표의 중복된 미정 표현보다 이 결정이 우선한다.

## 데이터 정책 확정 — P-057~066

수집/프로젝트 식별/분류·자료 보존/분석 보존·30일 오류 로그/백업·선택 분석 기본 꺼짐·내보내기/삭제·인사이트 권한/공개 집계 기준·일일 집계를 확정했다. [확정 데이터 정책](22_data_decisions.md)을 최신 기준으로 적용한다. 이전의 보존/동의 전면 미정 표현은 이 결정으로 대체하며 정책 문구·필드·권한/삭제의 실제 구현 검증은 남아 있다.
