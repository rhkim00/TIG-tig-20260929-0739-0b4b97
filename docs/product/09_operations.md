## 약관 확인과 실행 기능 출시

P-010의 사용자 조건을 충족하도록 [provider 검토](12_provider_review.md)의 구독 기반 작업 교환·자동 시작 허용 범위를 확인한다.
코드가 동작하는 것과 약관 조건이 충족된 것을 별도로 보고한다. 불명확한 경우 자동 시작을 허용된 기능으로 안내하지 않는다.
실행 방식·지원 범위·일정 조정은 유찬이 결정하며 API를 임의 도입하지 않는다.

## 출시 기준 제안

신규 외부 계정의 가입, repo 연결, Task 작성·예치, 수락, AI 작업, 제출, 수정 요청/승인,
TIG 지급/환불을 실제 배포 환경에서 검증한다. 두 AI 도구와 지원 OS의 테스트 범위를 명시한다.
권한 없는 접근, 중복 지급, timeout, 연결 끊김, 검증 실패를 재현하고 대응 결과를 기록한다.
설치 안내·문의 채널·장애 확인·복구 경로를 준비한다. 이 목록의 최종 필수 기준은 OPS-06에서 확정한다.

## 결정 후 반영

관련 질문 ID에 확정 P-xxx를 연결하고, 동작·예외·완료 조건 및 영향받는 작업/계약을 갱신한다.

## 운영 방향 확정 — P-054·055

월 인프라 예산 상한 100달러, 문의 이메일, 일일 DB 백업과 출시 전 복구/외부 거래/정산/권한 검증을 승인했다. 지급 이후 신고·남용은 운영자 검토, 자동 회수/제재는 하지 않는다. 실제 업체 견적과 구매/배포는 별도다.
승인 원문과 범위는 [결정 묶음 2](20_decision_batch_two.md) 및 [확정 기록](00_confirmed.md)을 따른다. 이전 질문 표의 중복된 미정 표현보다 이 결정이 우선한다.

## 데이터 정책 확정 — P-057~066

수집/프로젝트 식별/분류·자료 보존/분석 보존·30일 오류 로그/백업·선택 분석 기본 꺼짐·내보내기/삭제·인사이트 권한/공개 집계 기준·일일 집계를 확정했다. [확정 데이터 정책](22_data_decisions.md)을 최신 기준으로 적용한다. 이전의 보존/동의 전면 미정 표현은 이 결정으로 대체하며 정책 문구·필드·권한/삭제의 실제 구현 검증은 남아 있다.
