## 사용량·작업 이벤트 연동

P-018~020: 공식 한도 metadata에 따른 알림, 작업 이벤트에 따른 인계 초안 보존, 가용 보조 모델의 인계 정리를 설계한다.
유료 추론 API 없이 사용할 수 있는 공식 로컬 인터페이스의 근거와 제약은 [사용량 문서](14_usage_and_drafts.md)를 따른다.
UX 예시: “현재 5시간 한도의 90%를 사용했어요. 저장된 인계 초안으로 작업을 맡길까요?” 수치는 설명용이다.

## 자연어 요청 연동

P-014·015에 따라 기존 AI가 Tokenisgold 규칙과 작업 API를 사용할 연결 기능을 설계한다.
skill/plugin/MCP/CLI 중 방식은 미정이며, Git 작업과 예치/claim은 서버의 권한·검증 절차를 따른다.
잔여량·플랜 공유는 [FLOW-04](13_agent_workflow.md)의 출처/시각/알 수 없음 처리와 함께 확정한다.
사용자 예시: “TIG 벌 작업 찾아줘” → 조건에 맞는 추천 → “Yes” → 로컬 수행.

## 기존 환경 활용의 경계

공식 도구가 관리하는 기존 로그인을 사용한다. Tokenisgold가 provider token을 추출·복제·서버에 업로드하지 않는다.
구독 보유, CLI 설치, CLI 로그인, 실행 권한/한도는 별도 상태로 취급한다. 준비된 사용자는 중복 설정을 건너뛰도록 설계한다.
인증 만료·미설치·구독 제한은 해당 문제 해결 안내만 보여준다. API 과금으로 몰래 전환하지 않는다.

## 제품 지원과 개발 도구 구분

제품 사용자는 지원 범위 안에서 Codex CLI 또는 Claude Code를 선택한다.
개발자 두 사람의 AI 도구 선택(P-006)은 이와 별개이며 바뀔 수 있다.

도구 이름만으로 구독 종류·실제 모델·reasoning 검증 가능성을 단정하지 않는다.
어댑터 구현 전에 공식 문서와 실제 최소 실행으로 입력·결과·권한·metadata를 확인한다.
Tokenisgold의 AI credential 수집과 서버에서 consumer 구독 라우팅 금지 원칙은 유지한다.
